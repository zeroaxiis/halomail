Documentation & API Reference

Integrate contact forms, embed calendar scheduling, and interact directly with HaloMail ConnectRPC endpoints.

Overview

HaloMail provides two core capabilities backed by one unified infrastructure:

  • Contact Forms: Drop a lightweight widget into your site or post JSON directly from your backend. Messages are spam-scored, encrypted, saved in your dashboard, and instantly forwarded to your inbox.
  • Meeting Scheduling: Connect Google Calendar to automatically calculate availability across timezones, provision Google Meet links, and handle confirmations, rescheduling, and cancellations.

1Quickstart: 2-Line Form Embed

The fastest way to receive messages. Include the script tag and attach data-halomail with your access key to any form:

index.html
<!-- 1. Load the lightweight widget -->
<script src="https://api.halomail.app/widget.js" defer></script>

<!-- 2. Your form with access key -->
<form data-halomail="hl_key_your_access_key">
  <input type="text" name="name" placeholder="Your Name" required />
  <input type="email" name="email" placeholder="Your Email" required />
  <textarea name="message" placeholder="Your Message" required></textarea>
  <button type="submit">Send Message</button>
</form>
Automatic Field Handling: Standard inputs (name, email, message) are mapped automatically. Any additional input fields are preserved and stored in custom payload data.

2Access Keys

Access keys allow client-side websites to submit forms without exposing your private server API keys:

  1. Open your HaloMail Dashboard → Forms.
  2. Create or select a form to copy its Access Key (e.g. hl_key_9f82a17c).
Access keys are strictly scoped to submission. They cannot read past messages or modify form configurations.

3Widget DOM Events

The widget emits standard DOM events, allowing you to update your UI or display custom notifications:

JavaScript
const form = document.querySelector('form[data-halomail]');

form.addEventListener('halomail:sent', (e) => {
  console.log('Submission received:', e.detail);
  alert('Thank you! Your message has been delivered.');
});

form.addEventListener('halomail:error', (e) => {
  console.error('Submission failed:', e.detail);
  alert('Unable to send. Please check your connection and try again.');
});

4Plain HTML Form (No JavaScript)

If your website runs with JavaScript disabled, post directly to the endpoint using HTML form attributes:

HTML
<form action="https://api.halomail.app/halomail.contact.v1.MessageService/SubmitMessage" method="POST">
  <input type="hidden" name="access_key" value="hl_key_your_access_key" />
  <input type="text" name="sender_name" placeholder="Your Name" required />
  <input type="email" name="sender_email" placeholder="Your Email" required />
  <textarea name="data[message]" placeholder="Your Message" required></textarea>
  <button type="submit">Send Message</button>
</form>

5React & Next.js

Build a bespoke contact form with native React state management and Tailwind CSS:

ContactForm.tsx
"use client";

import { useState } from "react";

export function ContactForm() {
  const [status, setStatus] = useState<"idle" | "sending" | "success" | "error">("idle");

  async function handleSubmit(e: React.FormEvent<HTMLFormElement>) {
    e.preventDefault();
    setStatus("sending");

    const data = new FormData(e.currentTarget);

    try {
      const res = await fetch("https://api.halomail.app/halomail.contact.v1.MessageService/SubmitMessage", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          access_key: "hl_key_your_access_key",
          sender_name: data.get("name"),
          sender_email: data.get("email"),
          data: { message: data.get("message") },
          honeypot: data.get("_hl_hp") || "",
        }),
      });

      if (!res.ok) throw new Error("Submission rejected");
      setStatus("success");
      e.currentTarget.reset();
    } catch {
      setStatus("error");
    }
  }

  return (
    <form onSubmit={handleSubmit} className="flex flex-col gap-4 max-w-md">
      <input name="name" placeholder="Your Name" required className="border p-2 rounded" />
      <input name="email" type="email" placeholder="Your Email" required className="border p-2 rounded" />
      <textarea name="message" placeholder="Message" required className="border p-2 rounded" />

      {/* Honeypot field */}
      <input name="_hl_hp" tabIndex={-1} style={{ display: "none" }} autoComplete="off" />

      <button type="submit" disabled={status === "sending"}>
        {status === "sending" ? "Sending..." : "Send Message"}
      </button>

      {status === "success" && <p className="text-emerald-500">Message delivered successfully!</p>}
      {status === "error" && <p className="text-red-500">Failed to send message. Please try again.</p>}
    </form>
  );
}

6Honeypot Anti-Spam Defense

Protect your forms from automated spam bots without adding intrusive CAPTCHAs by adding an off-screen input named _hl_hp:

HTML Honeypot
<!-- Humans never see or fill this field; bots fill it automatically -->
<input type="text" name="_hl_hp" style="position: absolute; left: -9999px;" tabIndex="-1" autoComplete="off" />

7Custom Thank-You Redirects

Redirect visitors to a custom confirmation page after submitting by specifying data-redirect:

HTML
<form data-halomail="hl_key_your_access_key" data-redirect="https://yoursite.com/thanks">
  <!-- Fields -->
</form>

API Reference & Protocol

HaloMail speaks standard ConnectRPC with JSON serialization over HTTP/1.1 and HTTP/2.

ScopeHeaderUsage
PublicNoneForms submissions, listing open slots, booking meetings.
ServerAuthorization: ApiKey hl_live_...Backend-to-backend requests using API keys.
UserAuthorization: Bearer <jwt>User session tokens from dashboard login.

Reschedule & Cancel API

Invitees can modify or cancel appointments using opaque tokens delivered in their confirmation emails.

Reschedule Booking

POST /halomail.scheduling.v1.BookingService/RescheduleBooking Public (Token)
cURL
curl -X POST https://api.halomail.app/halomail.scheduling.v1.BookingService/RescheduleBooking \
  -H "Content-Type: application/json" \
  -d '{
    "reschedule_token": "tok_resched_89a1b2c3",
    "new_start": "2026-06-16T15:00:00Z"
  }'

Cancel Booking

POST /halomail.scheduling.v1.BookingService/CancelBooking Public (Token)
cURL
curl -X POST https://api.halomail.app/halomail.scheduling.v1.BookingService/CancelBooking \
  -H "Content-Type: application/json" \
  -d '{
    "cancel_token": "tok_cancel_45d6e7f8",
    "reason": "Scheduling conflict"
  }'

Webhooks & HMAC Verification

Deliver real-time HTTP POST alerts for events: booking.created, booking.cancelled, booking.rescheduled, and message.received.

Verifying Signatures

Node.js / Express
import crypto from "node:crypto";

function verifyWebhook(payloadRaw, signatureHeader, secret) {
  const hmac = crypto.createHmac("sha256", secret);
  const digest = "sha256=" + hmac.update(payloadRaw).digest("hex");
  return crypto.timingSafeEqual(Buffer.from(digest), Buffer.from(signatureHeader));
}
